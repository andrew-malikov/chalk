# Chalk

If `mcp__chalk__*` tools are available, use them instead of this skill.

Chalk serves its own instructions. Before authoring, run `chalk api session_get_instructions '{}'` and follow the result. Pass `'{"topic":"scratchpad"}'` to explain code visually. If Chalk is not running, the response says how to start it.
