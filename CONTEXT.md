# Review

Review lets authors explain code changes against specific source revisions.

## Language

**Headless authoring**:
Creating and editing a Review without installing or running the desktop application, including from a CI job.

**Local review**:
A Review of user-provided local source, without GitLab discussions.

**GitLab MR review**:
A Review of a GitLab merge request, including its discussions and source in a repository managed by Chalk.

**Review checkout**:
A local checkout used to inspect the changes being reviewed, separate from the checkout where the user edits code.

**Editing checkout**:
A local checkout where the user develops changes. Its state can evolve independently of the Review checkout.
